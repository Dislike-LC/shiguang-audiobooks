拾光听书
一款简约的 Android 本地电子书阅读与听书应用。导入书籍，即可自由切换阅读与聆听。
功能
- 本地导入：支持 TXT、EPUB，兼容常见中文文本编码。
- 沉浸阅读：全屏分页，支持正常、护眼、墨水模式，以及字号、字体和章节目录设置。
- 文字听书：当前段落高亮与自动跟随，支持进度拖动、语速调整和定时关闭。
- 声音预设：提供男声／女声切换，以及抒情、历史、逻辑三种朗读风格。
- 后台播放：接入 Android 媒体控制，支持通知栏和锁屏的播放、暂停及进度控制。
- 横屏适配：横屏以正文为中心，搭配悬浮胶囊进度条和圆形播放按钮。
- 进度保存：自动保存本机书库、阅读位置和阅读偏好。
设计
以留白、柔和渐变和半透明玻璃卡片构建界面。书库只保留书籍与导入入口，让注意力回到文字和声音。

视觉参考 Apple 的简约设计与 Folia 的沉浸式文字播放体验，界面自行实现。
使用
支持 Android 8.0 及以上。安装 APK 后，导入 TXT 或 EPUB 文件，点击书籍开始阅读或听书。

朗读使用设备的系统文字转语音引擎，需要启用中文语音；离线朗读需提前安装相应语音数据。男声／女声与风格预设的实际效果依赖系统引擎。
本地与隐私
无需注册账号，不上传书籍，不内置书籍内容。书库与进度保存在本机，卸载应用或清除应用数据会移除这些内容。
